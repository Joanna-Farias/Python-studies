# Exercícios de Python

Coleção de exercícios práticos em Python, com foco em lógica de programação, estruturas de decisão e laços de repetição.

## Estrutura do projeto

```text
.
├── Basic/    # Exercícios de nível básico de programação (condicionais, loopings, convenções de escrita, etc)
│
└── README.md
```

## Divisão das pastas

| Pasta | Nível | Conteúdo |
|---|---|---|
| `Basic/` | Básico | Estruturas condicionais, estruturas de looping, convenções de escrita, variáveis, etc. |

> Novas pastas (intermediário, avançado, projetos) serão adicionadas conforme os estudos avançam.

## Exercícios

| Arquivo | Descrição |
|---|---|
| `aprovar_emprestimo.py` | Analisa dados informados pelo usuário e decide se um empréstimo é aprovado |
| `calculo_media.py` | Calcula a média de notas |
| `jokenpo.py` | Jogo de pedra, papel e tesoura |
| `periodo_alistamento.py` | Verifica a situação do alistamento militar com base na idade |
| `tipos_triangulo.py` | Classifica um triângulo a partir dos lados informados |
| `exercism_1.py` a `exercism_6.py` | Soluções de exercícios da plataforma [Exercism](https://exercism.org/tracks/python) |

## Conceitos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados (`input` / `print`)
- Operadores aritméticos, lógicos e de comparação
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de looping (`while`, `for`)
- Funções
- Convenções de escrita (PEP 8)
- Validação de dados

## Como executar

1. Tenha o [Python 3](https://www.python.org/downloads/) instalado.
2. Clone o repositório:
   ```bash
   git clone https://github.com/Joanna-Farias/NOME-DO-REPOSITORIO.git
   ```
3. Entre na pasta e execute o arquivo desejado:
   ```bash
   cd NOME-DO-REPOSITORIO/Basic
   python jokenpo.py
   ```
